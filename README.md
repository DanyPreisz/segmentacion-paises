# Segmentación de Países

Proyecto de clustering listo para Google Colab. Incluye EDA, Elbow, Silhouette y K-Means.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/segmentacion-paises/blob/main/segmentacion_paises_colab.ipynb)

## Contenido

- Simulación de indicadores socioeconómicos
- EDA (histogramas, scatter)
- Elbow + Silhouette para elegir k
- K-Means final
- Visualización de clusters
- Perfil de segmentos
- Conclusiones

Dataset: datos simulados de países
